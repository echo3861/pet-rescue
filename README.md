# pet-rescue
# 🐾 寵物防走失救援系統 (Pet Rescue System)

免充電數位救援系統。

## 💡 關於本產品

這是一套專為毛孩設計的智慧防走失救援平台。路人無需下載任何 App，使用手機感應 NFC 吊牌或掃描 QR Code，即可秒速開啟專屬救援頁面。

### 🌟 核心特色

- **0 訂閱費、永久免充電**：一次購買，終身享受安全防護。
- **雙模式隱私控制**：
  - **平時模式**：作為毛孩的數位名片，展示寵物美照與 Instagram 追蹤連結。
  - **走失模式**：飼主自主開啟緊急聯絡管道，提供一鍵撥號與路人即時留言功能。
- **即時定位通報**：路人感應後自動觸發區域與定位通知，第一時間將位置傳送給飼主。
- **無障礙體驗**：免註冊、免登入，讓熱心路人能在 10 秒內完成救援通報。
